## 在室表示と更新のタイミング

| 状況 | 表示の目安 |
| --- | --- |
| PCが `iis-lab` に接続 | 在室推定 |
| 別のWi-Fiに接続 | 研究室Wi-Fi外 |
| 権限不足、判定不能、最終報告から15分以上経過 | 確認中 |

- PCは約5秒ごとにWi-Fiを確認し、変化時と約5分ごとに報告します。送信間隔は最短30秒です。
- Webは表示中に約5分ごとに自動更新します。「更新する」で保存済みの最新報告を取得できます。
- Webの更新操作はPCに再確認を要求するものではありません。
- スリープ・電源オフ・インターネット未接続中は報告できません。直前の表示がしばらく残ることがあります。
- 判定対象はPCです。PCを置いて外出すると在室のままになるため、正確な出欠・勤怠の記録としては使えません。

## 導入できたか確認する

1. `iis-lab` に接続し、送信後にWebで「在室推定」になることを確認します。
2. 別のWi-Fiに切り替え、送信後に「研究室Wi-Fi外」になることを確認します。
3. PCからログアウトして再ログインし、アプリを手動で開かなくても最終報告時刻が進むことを確認します。

## 停止・再開・状態確認

展開したフォルダ内のファイルを使います。Macは `.command`、Windowsは `.cmd` です。

| ファイル名 | 操作 |
| --- | --- |
| Start | 停止したアプリを再開 |
| Stop | 今だけ停止。次回PCログイン時は再開 |
| Status | 動作状態・Wi-Fi判定・送信状態を確認 |
| Uninstall | 停止してログイン時の自動起動を解除 |

**Uninstallはデータを完全削除しません。** アプリ・名前・送信キーを保持します。Web上の名前も残るため、削除や名前変更、PC交換は配布担当者に連絡してください。

## 困ったとき

- **名前が出ない**: 初回登録が完了しているか、インターネットに接続しているか確認します。
- **同じ名前を登録できない**: すでに登録済みのPCなら再登録せず利用します。PC交換の場合は担当者へ連絡します。
- **確認中のまま**: Statusで送信状態を確認し、位置情報の許可、ネット接続、スリープ状態を確認します。
- **表示が変わらない**: PCの送信とWebの更新には時間差があります。最終報告時刻も確認します。
- **インストールできない**: OSのバージョンとエラー画面を担当者に伝えてください。送信キーや `.env` は共有しないでください。

このリポジトリのURLを研究室メンバーに共有してください。各自がREADMEから対応するZIPをダウンロードできます。インストール済みのフォルダを他人にコピーせず、Releasesの未登録ZIPを配布します。

このリポジトリは配布案内用です。公開するものはREADMEと配布ZIP・ハッシュで、サーバーの秘密鍵や各自の端末設定は含みません。Windows版にはPython公式の組み込みランタイムと、そのライセンスを同梱しています。
