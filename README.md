# 研究室 在室確認

- 種別: 手順書
- 作成日: 2026-10-09
- 担当: dev
- 目的: 研究室メンバー向けのアプリ配布と初回設定
- 状態: 進行中（試作版・配布先での実機確認が必要）

PCが研究室のWi-Fi `iis-lab` に接続しているかを確認し、Webに在室状況を表示するアプリです。
初回に自分の名前を登録すると、次回からPCへのログイン時に自動起動します。

**[在室状況を見る](https://iis-lab-presence.vercel.app/)** — ログイン不要。スマホ・自宅・出先からも閲覧できます。

## ダウンロード

| PC | 配布ZIP | 対応環境 |
| --- | --- | --- |
| Mac | [Mac版 0.6.0 をダウンロード](https://github.com/sysysy06/iis-lab-presence/releases/download/v0.6.0/IISLabPresence-Mac-Universal-0.6.0.zip) | macOS 13以降、Apple Silicon / Intel |
| Windows | [Windows版 0.6.0 をダウンロード](https://github.com/sysysy06/iis-lab-presence/releases/download/v0.6.0/IISLabPresence-Windows-x64-0.6.0.zip) | Windows 11 x64（Intel / AMD） |

PythonやXcodeの追加インストールは不要です。Windows ARM64・32ビット版は対象外です。
[配布一覧と検証用SHA-256](https://github.com/sysysy06/iis-lab-presence/releases/tag/v0.6.0)も確認できます。
GitHubの「Code → Download ZIP」や「Source code」ではなく、上の**自分のOS用の配布ZIP**をダウンロードしてください。

## 最初に確認すること

- 名前・在室推定・最終報告時刻はインターネットに公開されます。研究室メンバー限定の閲覧ではありません。
- 研究室で普段使うPCにインストールしてください。まずMac・Windows各1台で確認してから全員へ配布します。
- 登録上限は現在30件です。同じ名前は登録できないため、同姓同名の人は区別できる表示名にしてください。
- 名前の登録は自己申告です。パスワード登録や送信キーのコピーは不要です。

## Macの初回設定

1. Mac版のZIPをダウンロードして、ダブルクリックで展開します。
2. 展開したフォルダの **Install.command** を開きます。先にWifiProbe.appを直接開かないでください。
3. アプリの初回設定で自分の表示名を入力し、**この名前で登録**を押します。
4. Wi-Fiを確認するための位置情報利用を許可します。GPS座標は取得しません。
5. **OpenWebsite.webloc** または上の在室サイトを開き、自分の名前を確認します。

ウィンドウを閉じても検知と送信は続きます。Macへの次回ログイン時から自動起動します。

この試作版はローカル署名のみで、AppleのDeveloper ID署名・公証はありません。初回にmacOSや学校の管理設定で実行が止まる場合があります。警告が出た場合は配布担当者に画面の内容を伝え、[Appleの案内](https://support.apple.com/ja-jp/102445)に沿って確認してください。セキュリティ機能の無効化は不要です。

## Windowsの初回設定

1. Windows版のZIPをダウンロードし、右クリックして **すべて展開** します。
2. 展開したフォルダの **Install.cmd** をダブルクリックします。ZIP内から直接実行しないでください。
3. 自分の表示名を入力してEnterを押します。
4. 「名前の登録とログイン時の自動起動設定が完了しました」と出たら完了です。
5. **OpenWebsite.url** または上の在室サイトを開き、自分の名前を確認します。

黒い画面を開いたままにする必要はありません。Windowsへの次回ログイン時から自動起動します。Wi-Fi取得で権限不足になる場合はWindowsの位置情報設定を確認します。実行が学校の管理設定で拒否される場合は管理者に相談してください。

## 在室表示と更新のタイミング

| 状況 | 表示の目安 |
| --- | --- |
| PCが `iis-lab` に接続 | 在室推定 |
| 別のWi-Fiに接続 | 研究室Wi-Fi外 |
| 権限不足、判定不能、最終報告から15分以上経過 | 確認中 |

- PCは約5秒ごとにWi-Fiを確認し、変化時と約5分ごとに報告します。送信間隔は最短30秒です。
- Webは表示中に約5分ごとに自動更新します。「更新する」で保存済みの最新報告を取得できます。
- Webの更新操作はPCに再確認を要求するものではありません。
- スリープ・電源オフ・インターネット未接続中は報告できません。直前の表示がしばらく残ることがあります。
- 判定対象はPCです。PCを置いて外出すると在室のままになるため、正確な出欠・勤怠の記録としては使えません。

## 導入できたか確認する

1. `iis-lab` に接続し、送信後にWebで「在室推定」になることを確認します。
2. 別のWi-Fiに切り替え、送信後に「研究室Wi-Fi外」になることを確認します。
3. PCからログアウトして再ログインし、アプリを手動で開かなくても最終報告時刻が進むことを確認します。

## 停止・再開・状態確認

展開したフォルダ内のファイルを使います。Macは `.command`、Windowsは `.cmd` です。

| ファイル名 | 操作 |
| --- | --- |
| Start | 停止したアプリを再開 |
| Stop | 今だけ停止。次回PCログイン時は再開 |
| Status | 動作状態・Wi-Fi判定・送信状態を確認 |
| Uninstall | 停止してログイン時の自動起動を解除 |

**Uninstallはデータを完全削除しません。** アプリ・名前・送信キーを保持します。Web上の名前も残るため、削除や名前変更、PC交換は配布担当者に連絡してください。

## 困ったとき

- **名前が出ない**: 初回登録が完了しているか、インターネットに接続しているか確認します。
- **同じ名前を登録できない**: すでに登録済みのPCなら再登録せず利用します。PC交換の場合は担当者へ連絡します。
- **確認中のまま**: Statusで送信状態を確認し、位置情報の許可、ネット接続、スリープ状態を確認します。
- **表示が変わらない**: PCの送信とWebの更新には時間差があります。最終報告時刻も確認します。
- **インストールできない**: OSのバージョンとエラー画面を担当者に伝えてください。送信キーや `.env` は共有しないでください。

このリポジトリのURLを研究室メンバーに共有してください。各自がREADMEから対応するZIPをダウンロードできます。インストール済みのフォルダを他人にコピーせず、Releasesの未登録ZIPを配布します。

このリポジトリは配布案内用です。公開するものはREADMEと配布ZIP・ハッシュで、サーバーの秘密鍵や各自の端末設定は含みません。Windows版にはPython公式の組み込みランタイムと、そのライセンスを同梱しています。
