# 研究室 在室確認｜ダウンロード・初回設定

- 種別: 手順書
- 作成日: 2026-10-09
- 担当: dev
- 目的: 研究室メンバー向けのアプリ配布
- 状態: 完了（配布ページ。アプリは試作版）

研究室で使うPCに入れて、**最初に自分の名前を登録するだけ**。以降はPCへのログイン時に自動起動し、研究室のWi-Fi接続から在室状況を報告します。

**[在室状況を見る →](https://iis-lab-presence.vercel.app/)**  
閲覧だけならインストール不要。スマホ・自宅・出先から、ログインなしで見られます。

## 1. 自分のPC用をダウンロード

| Mac | Windows |
| --- | --- |
| **[Mac版をダウンロード](https://github.com/sysysy06/iis-lab-presence/releases/download/v0.6.0/IISLabPresence-Mac-Universal-0.6.0.zip)** | **[Windows版をダウンロード](https://github.com/sysysy06/iis-lab-presence/releases/download/v0.6.0/IISLabPresence-Windows-x64-0.6.0.zip)** |
| macOS 13以降・Apple Silicon / Intel | Windows 11・Intel / AMDの64ビット版 |
| バージョン 0.6.0（試作版） | バージョン 0.6.0（試作版） |

Pythonなどの追加インストールは不要です。Windows ARM64・32ビット版は対象外です。
**上のリンクからダウンロードしてください。** GitHubの「Code → Download ZIP」「Source code」にはアプリが入っていません。

## 2. 展開して名前を登録

### Mac

1. ダウンロードしたZIPをダブルクリックして展開します。
2. フォルダ内の **Install.command** を開きます。
3. 自分の表示名を入力し、**この名前で登録**を押します。
4. Wi-Fi確認のための**位置情報利用を許可**します。GPS座標は取得しません。

先にWifiProbe.appを直接開かず、Install.commandから始めてください。
Mac版はApple公証がないため、実行時に警告が出る場合があります。開けないときは画面の内容を配布担当者へ伝えてください。[Appleの確認方法](https://support.apple.com/ja-jp/102445)

### Windows

1. ダウンロードしたZIPを右クリックして **すべて展開** します。
2. フォルダ内の **Install.cmd** をダブルクリックします。
3. 自分の表示名を入力してEnterを押します。
4. **「名前の登録とログイン時の自動起動設定が完了しました」** と出れば完了です。

ZIP内から直接実行しないでください。Wi-Fiを取得できない場合は、Windowsの位置情報サービスとアプリの位置情報利用の許可を確認してください。学校の管理設定で実行できない場合は管理者へ相談してください。

## 3. 自分の名前が表示されるか確認

**[在室一覧を開く →](https://iis-lab-presence.vercel.app/)**

研究室のWi-Fi **iis-lab** に接続していると「在室推定」、別のWi-Fiなら「研究室Wi-Fi外」になります。
送信と画面更新には時間差があり、Webは表示中に約5分ごとに自動更新します。

一度設定すれば、毎回名前を入力する必要はありません。アプリの画面を閉じても検知と送信は続きます。

## 利用前に確認してください

- **名前・在室推定・最終報告時刻はインターネットに公開されます。** 研究室内だけに限定したサイトではありません。
- 登録上限は**50件**です。同じ名前は登録できません。PC交換や名前変更は配布担当者に連絡してください。
- PCを置いて外出すると在室のままになるなど、実際の在室と異なる場合があります。
- スリープ・電源オフなどで15分以上報告がない場合は「確認中」になります。
- **試作版です。** Windows実機・別Macでの初回導入・再ログイン後の自動起動は未検証のため、まず各OSの1台で確認してください。

## 困ったとき・利用を止めたいとき

**[詳しい使い方・よくある質問](docs/2026-10-09_研究室在室確認_手順書.md)**

展開したフォルダの **Status** で状態確認、**Stop** で一時停止、**Start** で再開できます。**Uninstall** は自動起動を解除しますが、名前や送信キーは残ります。

問題があれば、このページを案内した研究室の配布担当者へ、OSのバージョンとエラー画面を伝えてください。送信キーや個人設定は共有しないでください。
